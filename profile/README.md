## 👋 欢迎来到 bingwu-templates

这里是我的项目模板库，整理常用的前端后台骨架与 TypeScript 库模板，让新项目从熟悉的技术栈开始。

把重复的配置沉淀为模板，把时间留给业务，让下一个项目轻装开始。

## 🧭 模板导航

| 模板 | 用途 | 技术栈 |
| --- | --- | --- |
| [pure-admin-thin](https://github.com/bingwu-templates/pure-admin-thin) | vue-pure-admin 精简版，适合基于 Element Plus 搭建后台项目 | Vue 3 · TypeScript · Vite · Element Plus |
| [art-design-pro-thin](https://github.com/bingwu-templates/art-design-pro-thin) | 注重视觉设计与使用体验的后台模板 | Vue 3 · TypeScript · Vite · Element Plus |
| [shadcn-react-template](https://github.com/bingwu-templates/shadcn-react-template) | 基于 shadcn/ui 的 React 后台骨架，保留仪表盘、任务与用户管理等页面 | React · TypeScript · Vite · Tailwind CSS · shadcn/ui |
| [starter-ts](https://github.com/bingwu-templates/starter-ts) | TypeScript 库项目模板，覆盖构建、检查、测试与发布流程 | TypeScript · pnpm · Turborepo · Oxc · tsdown · Vitest · Changesets |

## 🚀 开始使用

选择适合的模板，进入仓库查看 README，按项目说明安装依赖并启动。

也可以搭配 [bingwu-cli](https://github.com/bingwu-devkit/bingwu-cli) 管理常用模板与脚手架，让创建项目更顺手。
